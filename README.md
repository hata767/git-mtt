# git-mtt

A starter repository initialized locally and version-controlled with Git.

## Getting started

Clone the repository:

```bash
git clone git@github.com:hata767/git-mtt.git
cd git-mtt
```

## Layout

```
git-mtt/
├── README.md
└── .gitignore
```

## Next steps

- Add your source code or documents.
- Commit with a descriptive message: `git add -A && git commit -m "feat: ..."`.
- Push to GitHub: `git push -u origin main`.
